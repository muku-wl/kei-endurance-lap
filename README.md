# 軽自動車耐久レース｜ラップ記録Webアプリ

スマホ・PCから利用できる、静的HTMLのラップタイム記録アプリです。

## 主な機能

- 102345 → 1:02.345、59876 → 0:59.876 の数字入力
- セッションの追加、名前変更、削除、セッション内記録のみクリア
- ドライバー登録、周回/タイム/メモ修正、取り消し
- 周回抜け/入力矛盾の警告、集計
- 通常は最新8周を表示し、全周回の確認・編集も可能
- 詳細なレース分析画面、真の .xlsx 形式のExcel出力、JSONバックアップ・復元
- 共有用スプレッドシート（.xlsx）の出力：総合結果・ドライバー別・ラップ推移・セッション別全周回
- サーバー不要、外部JavaScriptライブラリ不要

## GitHub Pagesで公開

1. GitHubで新規の **Public** リポジトリを作成（例 `kei-endurance-lap`）。
2. このフォルダにある `index.html`、`.nojekyll`、`README.md` をリポジトリのルートにアップロード。
3. `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選択。
4. Branchを `main`、フォルダを `/ (root)` にして `Save`。
5. `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` をSafari/Chromeで開く。

## 記録画面の使い方

- 普段は「セッション選択 → ドライバー選択 → ラップタイム入力 → 記録」だけで操作できます。
- メモ欄はピットイン、メンバー交代などに利用できます。
- 「詳細入力・ドライバー登録」から総合タイム、周回数の手動設定、新規ドライバー登録を行えます。
- 最近の8周を最初に表示し、「全件を表示」で過去の全記録の編集に切り替えられます。
- セッション追加・名前変更・記録クリア・セッション削除は「セッション管理」の中にあります。
- Excel出力・LINE用シート出力・JSONバックアップと復元は「記録の保存・LINE共有・復元」にまとめています。
- 簡易レポートは廃止し、詳細なレース分析に一本化しました。

## レース分析（ドライバーごとの成績・交代履歴）

入力画面の「📈 詳細なレース分析を見る」または [分析ダッシュボード](https://muku-wl.github.io/kei-endurance-lap/analysis.html) から開きます。

- セッションごとのラップタイム推移グラフ（ドライバー色分け、交代位置の縦線）
- 各ドライバーの交代・ピット周回を除いた平均・ベスト・ばらつき、前半／後半ペース変化
- 各ドライバーのスティント（担当した連続周回、走行時間、平均）
- 誰から誰へ・何周目・レース開始後いつ交代したか、交代前後ラップの通常ペースとの差
- 平均に含めない周回の理由を全ラップ表で確認

標準設定は、交代直前と直後の各1周、メモに「ピット」「交代」「給油」等がある周回、要確認・ラップ不明の周回を平均から除外します。交代前後は各0／1／2周に変更でき、遅い外れ値を追加除外するオプションもあります。

注意：ドライバー交代位置は記録のドライバー名の切替からの推定です。ピット入庫／出庫の時刻を記録していないため、ピット停止時間そのものを正確に算出することはできません。分析画面は同じブラウザ内の記録を閲覧するものであり、他人と記録が自動同期されるものではありません。

## LINEで結果を共有するには

1. 記録画面の「記録の保存・LINE共有・復元」を開き、「📗 LINE共有用スプレッドシート」を押して `.xlsx` を保存します。
2. Googleドライブにファイルをアップロードします。
3. Googleスプレッドシートで開き、必要ならGoogleスプレッドシート形式で保存します。
4. 「共有」→「一般的なアクセス」を「リンクを知っている全員（閲覧者）」にして、共有URLをLINEで送ります。
5. 共有用ブックの先頭シートが総合結果、次にドライバー別成績、ラップ推移、各セッションの記録です。

※共有設定の変更はGoogleアカウント側で行います。アプリからGoogleドライブへ自動アップロードはしません。共有リンクを知る人は閲覧可能になります。
※Excel用のラップ推移グラフを含みますが、Googleスプレッドシートに変換するとグラフが保持されない場合があります。その場合も「ラップ推移」シートの元データは残ります。

## 大事な注意事項

- 公開されるのは空のアプリ本体です。このフォルダに過去の記録やJSONバックアップは含まれません。
- 入力データはブラウザの `localStorage` に端末ごとに保存されます。**他の端末には自動同期しません**。
- URLを他の人に送っても、あなたのレース記録は送られません。共有にはGoogleスプレッドシートへのアップロードやJSON/Excelの受け渡しが必要です。
- PCの旧HTMLで保存した記録は公開サイトへ自動では移動しません。旧アプリでJSONバックアップを書き出し、公開サイトの「復元」で読み込んでください。
- Safariのプライベートブラウズは避け、レース中も定期的にJSONバックアップを保存してください。
- GitHub Pagesのサイトは通常、誰からでもアクセスできます。個人情報や非公開記録をリポジトリへアップロードしないでください。
